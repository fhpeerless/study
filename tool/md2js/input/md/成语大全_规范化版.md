# 真题高频成语整理

## 一、形容事情难易程度

| 成语 | 释义 |
|------|------|
| 轻而易举 | 形容事情容易做，不费力气。 |
| 易如反掌 | 形容事情极容易，像翻手掌一样。 |
| 一蹴而就 | 比喻事情一下子就成功。常用于否定句，表示事情不可能一下子完成。 |
| 一劳永逸 | 辛苦一次，把事情办好，以后就不再费事了。 |
| 万无一失 | 形容绝对不会出差错，非常有把握。 |
| 一锤定音 | 比喻凭一句话做出最终决定。 |
| 水到渠成 | 比喻条件成熟，事情自然会成功。 |
| 瓮中捉鳖 | 比喻手到擒来，轻易而有把握。 |
| 事半功倍 | 形容花费的气力小，收到的成效大。 |
| 游刃有余 | 比喻工作熟练，解决问题毫不费力。 |
| 难以为继 | 难以继续下去。 |
| 步履维艰 | 形容行动困难或事情进展艰难。 |
| 进退维谷 | 进退两难，形容处境困难。 |
| 望洋兴叹 | 比喻因力不胜任或没有条件而感到无可奈何。 |
| 大海捞针 | 形容极难找到。 |
| 鞭长莫及 | 比喻力量达不到。 |

## 八、形容方法与策略

| 成语 | 释义 |
|------|------|

| 因地制宜 | 根据各地的具体情况，制定适宜的办法。 |
| 对症下药 | 比喻针对具体情况决定解决问题的办法。 |
| 因势利导 | 顺着事情发展的趋势，加以引导。 |
